# 悬浮球美化与适配修复（FloatingNav FAB）

> 版本：v1.1 ｜ 日期：2026-09-29 ｜ 前置文档：[移动端浮动导航防遮挡](./移动端浮动导航防遮挡.md)

## 需求

1. **修复布局回归**：FAB（悬浮球）模式下展开横条被拉成纵向巨型胶囊、且展开后跳到左缘压住悬浮球（用户截图确认）。
2. **视觉美化**：悬浮球与展开横条质感粗糙，需按主题 token 规范做纯 CSS 美化（不引入 GSAP），并补触控目标、无障碍、safe-area 适配。
3. **层级修复**：RAG 抽屉（z-index 120）打开时悬浮球被遮住，需提升球层级使其仍可导航。

## 根因（两个 CSS 层叠缺陷，均系 FAB 改造时删掉旧规则引入）

| # | 缺陷 | 后果 |
|---|------|------|
| 1 | FAB 媒体查询未重置桌面态 `.floating-nav { top: 50% }`，与 `bottom: 14px` 同时生效 | 绝对定位纵向拉伸 → 巨型胶囊 |
| 2 | 媒体查询 `.floating-nav { left: 68px }`（特异性 0-1-0）打不过桌面 `.floating-nav.visible { left: 16px }`（0-2-0） | 展开后 `left` 被桌面规则抢走 → 横条压住球 |

对照 git 旧版：改造前的媒体查询带 `top: auto` 与 `.floating-nav.visible { left: 14px }`，FAB 化时被一并删除。

## 方案

### 一、布局修复（核心）

```css
@media (hover: none), (pointer: coarse), (max-width: 1024px) {
  .floating-nav {
    top: auto;                                      /* 缺陷1：清掉 top:50% */
    left: calc(68px + env(safe-area-inset-left, 0px));
    max-width: calc(100vw - 82px - env(safe-area-inset-left, 0px)); /* 防右溢出 */
  }
  .floating-nav.visible {
    left: calc(68px + env(...));                    /* 缺陷2：同特异性(0-2-0)、源顺序靠后 → 胜出 */
  }
}
```

### 二、视觉美化（纯 CSS）

- **悬浮球**：46×46 圆形、分层阴影 + `inset 0 1px 0` 内高光、`touch-action: manipulation` 关闭双击缩放延迟、入场 `fabHint` 呼吸光晕 2 次即停、`:active` 按压缩放、`:focus-visible` 描边、展开态强调色微光、窄视口桌面指针的悬停抬升。
- **图标交叉过渡**：`Menu`/`Close` 双图标叠放，展开时 Menu 旋出、Close 旋入（替代 `<component :is>` 生硬切换）。
- **按压波纹**：`::after` + `fabRipple` 关键帧在球内扩散淡出。
- **展开横条**：胶囊 `border-radius: 999px`、与球同款分层阴影、条目 `:nth-child` stagger（0/40/80/120ms）依次弹入、收起时 delay 归零整体淡出。
- **触控目标**：条目 44×44（iOS 下限）、图标 20px。

### 三、适配与无障碍

- **safe-area**：wrapper/横条的 `bottom/left` 用 `calc(... + env(safe-area-inset-*, 0px))`；`index.html` 无 `viewport-fit=cover`，当前 `env()` 恒为 0、零风险，**不改 index.html**（预留刘海屏适配）。
- **Esc 收起**：脚本监听 `window` keydown，`fabOpen` 开启时按 Esc 关闭（`onMounted`/`onBeforeUnmount` 注册与移除）。
- **层级**：wrapper `z-index: 100 → 130`，压过 RAG 抽屉 120 / 其 mask 110。
- **触屏细节**：`-webkit-tap-highlight-color: transparent`、`user-select: none`。
- **`prefers-reduced-motion: reduce`**：关闭呼吸光晕/波纹动画，过渡时长压到 0.01ms。

### 四、token 规范（改动中遵守）

- 组件内不硬编码强调色 `rgba(59,130,246,x)` → 一律 `--accent-soft` / `--accent-soft-strong` / `--accent-primary`。
- 圆角只用 `--radius-sm/md`；胶囊 `999px` 为既有用法保留。

## 层级结构（FAB 模式）

```
nav-wrapper (fixed, z-index 130)   ← 覆盖抽屉 120、其 mask 110
├── nav-backdrop  (fixed inset 0, z-index 1)
├── nav-fab       (relative,   z-index 2)
└── floating-nav  (fixed,      z-index 2)
```

## v1.1 变更：位置迁移 左下角 → 右侧中间

### 需求

用户反馈球放**右下角**会撞上两个常驻元素：`HomeView .knowledge-sphere`（120×120，`bottom:40; right:40`）与 `TimelineView .legend-fixed`（`bottom:24; right:24`），遂改为**右侧垂直居中**——与桌面 hover 竖条（左侧中部）视觉对称，且常驻元素零冲突。

### 方案（关键实现点）

```css
.nav-wrapper {            /* 左下小块 → 右侧全高锚点条 */
  top: 0; bottom: 0; left: auto; right: 0;
  width: 74px;            /* 14 边距 + 46 球 + 14 */
  display: flex; flex-direction: column;
  justify-content: center; align-items: flex-end;
  padding-right: calc(14px + env(safe-area-inset-right, 0px));
  pointer-events: none;    /* ★ 全高条不能拦截右侧页面点击 */
}
.nav-fab      { position: relative; pointer-events: auto; }   /* flex 居中，不占 transform */
.nav-backdrop { position: fixed; inset: 0; pointer-events: auto; }
.floating-nav {
  top: 50%;
  right: calc(68px + env(safe-area-inset-right, 0px));  /* 球左缘 + 8px 间距 */
  left: auto;
  max-width: calc(100vw - 82px - env(safe-area-inset-right, 0px));  /* 防左溢出 */
  transform: translateY(-50%) translateX(8px) scale(0.92);          /* 收起：向右(球方向)缩回 */
}
.floating-nav.visible { transform: translateY(-50%) translateX(0) scale(1); }
.nav-item              { transform: translateX(8px) scale(0.85); } /* 从球方向向左依次弹入 */
```

三个坑的规避：

1. **transform 冲突**：球若用 `top:50% + translateY(-50%)` 垂直居中，会与 hover/`active` 的 `scale` 互相覆盖导致跳位 → 改用 **flex 居中**，球不占 `transform`。
2. **横条居中**：横条已有 `translateX + scale` 状态机，把 `translateY(-50%)` **并入每个状态**（`translateY(-50%) translateX(...)`），不新增冲突。
3. **包含块**：`transform` 会让 `fixed` 子元素改以该元素为包含块 → wrapper **不加 transform**，`nav-backdrop`（遮罩）才仍是全屏 `inset:0`。
4. **pointer-events 继承**：`none` 会继承给子元素，故 `.nav-fab` / `.nav-backdrop` / 展开态 `.floating-nav` 显式 `auto`，收起态 `.floating-nav` 显式 `none`（不可点）。

### 展开方向反转

- 球在右、横条在球**左侧**向左弹出（原为向右弹）。
- 条目 stagger 方向随之反转：从球方向（右）向左依次弹入。
