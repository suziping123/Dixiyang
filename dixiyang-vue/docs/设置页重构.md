# 设置页重构（feat/settings-redesign）

> 范围: 前端 `dixiyang-vue/Dixiyang-vue3`（含直接依赖组件）+ 后端 `/userConfig/fontColors` 补端点
> 分支: `feat/settings-redesign`（基线 `73966a8`），提交 `9f24011` → `d94f22c`

## 需求

1. 设置页统一设计标准：token 化样式、Element Plus 图标、统一控件/弹窗/回车行为。
2. 删除"AI 化"风格与死设置（不存在的路由入口、无后端的假开关、调试面板）。
3. 修复直接依赖组件的缺陷：compact 背景选择器空渲染、按钮嵌套、误标首页高亮。
4. 前后端接口对齐：补齐前端已调用但后端缺失的 fontColors 端点。

## 第二轮修复（8 项体验问题）

### 1. Python 后端缺改密码端点
- `DixyangFast/src/dixiyang/routers/user.py` 新增 `POST /user/password`：bcrypt 校验 `oldPassword`、新密码 ≥6 位且不得与旧密码相同；复用 `auth_service._verify_pw/_hash_pw`。
- 接口详见 `DixyangFast/docs/用户与配置接口文档.md`。

### 2. 全局字体设置在其他页面无效
- **根因**：字号只写到 `body` 的 `--font-size-base`，而组件几乎全用 `rem`（基于 `html`，被媒体查询固定为 15/14/13/12px）；`font-family` 仅靠规则声明，可能被 Tailwind 预设覆盖。
- **修复**：
  - `useFontConfig.ts` 新增 `--font-size-user`（用户字号），并对 `html` 内联 `font-family`；
  - `main.css`：`html { font-size: calc(var(--font-size-user,16px) * var(--viewport-font,1)) }`，媒体查询改设 `--viewport-font` 系数（0.9375/0.875/0.8125/0.75，等价原值），`body` 字号改 `inherit`。

### 3. 登录页移动端适配
- `LoginView.vue` ≤768px：`auth-box` 改 `min(100%,400px)` 高度自适应；隐藏滑动 overlay，表单改静态流；登录/注册面板 `display` 切换；标题改静态定位、字号缩小。

### 4. 首页移动端封面过大
- `HomeView.vue` ≤768px：卡片网格由单列改**双列**（gap 14px、页面 padding 16px），单卡模式 `max-width` 320→240px。

### 5 + 8. 设置页移动端频繁滑动 / 侧边栏滚动消失
- **根因**：`.settings-container { overflow: hidden }` 创建滚动上下文，破坏 `position: sticky`；移动端分类条为 `static`。
- **修复**：`overflow: hidden → overflow-x: clip`（不破坏 sticky）；≤1024px 分类条 `sticky top:0` + 4 等分网格 tab（icon 上文字下）+ 标题/返回合并一行；切换分类时 `window.scrollTo(0)` 平滑回顶。

### 6. 浮动导航对移动端不友好
- `FloatingNav.vue` 新增 `@media (hover: none), (pointer: coarse)`：改为**左下角常驻圆角横条**（不依赖 hover 触发），条目 38px，隐藏左缘触发区。

### 7. 设置内容不占满 + 背景图下看不清
- `.settings-content` `max-width 860→1040px` 且 `margin: 0 auto`（居中）。
- 新 token `--surface-panel: rgba(13,13,15,0.86)`（main.css）；`SettingsSection`/`.settings-sidebar` 背景改用它 + `backdrop-filter: blur(16px)`，背景图开启时文字可读。

### 9. 设置页按钮宽度不一致
- `SettingRow`：stacked 行内控件 `align-items: center`，`.btn` 统一 `width:100%; max-width:320px`（修复 flex column 默认 stretch 占满）。
- `AccountSection .pwd-actions`、`AboutSection .about-actions`、`FontControl .reset-row` 统一居中 + 320px 上限（窄屏 column 时同样限制）。
