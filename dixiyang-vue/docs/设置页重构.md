# 设置页重构（feat/settings-redesign）

> 范围: 前端 `dixiyang-vue/Dixiyang-vue3`（含直接依赖组件）+ 后端 `/userConfig/fontColors` 补端点
> 分支: `feat/settings-redesign`（基线 `73966a8`），提交 `9f24011` → `d94f22c`

## 需求

1. 设置页统一设计标准：token 化样式、Element Plus 图标、统一控件/弹窗/回车行为。
2. 删除"AI 化"风格与死设置（不存在的路由入口、无后端的假开关、调试面板）。
3. 修复直接依赖组件的缺陷：compact 背景选择器空渲染、按钮嵌套、误标首页高亮。
4. 前后端接口对齐：补齐前端已调用但后端缺失的 fontColors 端点。

## 方案与改动

### 阶段1 — 设计 token（`9f24011`）
- `src/assets/main.css`：`html.theme-dark` 新增 `--radius-sm/md`、`--dur-fast/dur/ease-out`、`--danger/*`、`--accent-soft*`。

### 阶段2 — 设置页信息架构（`8ba760d`）
- `views/SettingsView.vue`：重写，4 分类（账号/外观/数据/关于），≤1024px 横向 tab，去发光去 spring 动画。
- `components/SettingsSection.vue`：去 `uppercase`/发光，标题+分隔线。
- 新增 `components/settings/`：`SettingRow`（label+desc+slot）、`AccountSection`（昵称/邮箱 `enterSubmit`、改密码接 `POST /user/password`、`confirmDelete` 登出）、`AppearanceSection`、`DataSection`（清理本地外观缓存）、`AboutSection`（不编造外链）。
- `assets/icon-utils.css`：全局 `.btn/.btn-primary/.btn-ghost/.btn-danger` 工具类。
- `composables/useBackgroundConfig.ts`：`syncToServer` 改传 `backgroundId: ''`（空串=清除，适配后端 `!= null` 才覆盖的语义）。

### 阶段3 — 外观组件精简（`ef93aec`）
- `components/FontControl.vue`：删 `mode` prop、字号缩放滑块（仅留 5 档预设）、"显示字体信息"调试面板。
- 新增 `components/settings/BgImageGrid.vue`：背景网格组件化（含上传卡/无背景卡/自定义删除，修复按钮嵌套），full 与 compact 弹层共用。
- `components/BackgroundControl.vue`：full=纯网格；compact=`el-popover` 触发按钮（修复 `HomeView`/`NovelPageHeader` 空渲染）；删死"主题"区块。
- `api/novelApi.ts`：`uploadBgImage` 返回类型 `{bgUrl}` → `string`，对齐后端 `Result<String>`。

### 阶段4 — 全局导航（`dac927f`）
- `components/FloatingNav.vue`：emoji → EP 图标（House/ChatDotRound/Setting）；删除不存在路由 `/discover` `/library` `/notifications` 死链；修复未匹配路由误标首页高亮（`-1` 不高亮）。

### 阶段5 — 后端补端点（`d94f22c`）
- `UserConfigController.java`：新增 `GET/POST /userConfig/fontColors`（复用 `font_colors_json` + `FontColorsDTO`），抽 `getOrCreate()` 统一四端点查询。
- `SecurityConfig.java`：permitAll 白名单补 `/userConfig/**`。
- 接口契约见 `dixiyang-engine/docs/后端接口文档.md`「用户配置接口」。

2. `npx eslint <本次改动文件>` 通过。
3. `mvn -DskipTests compile` 通过（后端）。
4. 手动验收：设置页 4 分类切换、昵称/邮箱回车保存、改密码三框、删除自定义背景、清空背景、上传背景、首页/章节页头部「背景」按钮弹层选择、侧边导航仅 3 项且当前页高亮正确。
