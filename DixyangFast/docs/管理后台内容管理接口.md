# 管理后台内容管理接口（广场帖子 / 灵感墙便签）

> 版本：v1.0 ｜ 日期：2026-10-18 ｜ 模块：`DixyangFast` `routers/admin.py` + `services/admin_content_service.py`
>
> 全部端点位于 `/api/admin/**`，走 `require_admin`（**仅后台会话 token**，`scope=admin` + `admin_session_id` 比对 + `role` 实时校验）；用户端 token 一律 403。
> 调用方：管理控制台 `admin.html`（独立入口）。总体背景见 [docs/管理后台独立化.md](../../docs/管理后台独立化.md) §12。

## 1. 端点总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/posts` | 帖子列表（全状态） |
| GET | `/api/admin/posts/{post_id}` | 帖子详情（正文/配图/标签/附件元信息） |
| PUT | `/api/admin/posts/{post_id}/status` | 平台下架 / 恢复 |
| DELETE | `/api/admin/posts/{post_id}` | 硬删除（级联清理） |
| GET | `/api/admin/posts/{post_id}/comments` | 帖子评论列表 |
| DELETE | `/api/admin/comments/{comment_id}` | 删除评论（回写计数与热度） |
| GET | `/api/admin/sticky` | 便签列表（全用户） |
| DELETE | `/api/admin/sticky/{note_id}` | 删除便签（连带正文文件） |

## 2. 帖子列表 `GET /api/admin/posts`

查询参数：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `page` | int | 1 | 页码 |
| `pageSize` | int | 20 | 每页条数 |
| `status` | `published` / `removed` / 空 | 空=全状态 | 状态筛选 |
| `category` | `idea`/`character`/`setting`/`timeline`/`tech` | 空=全部 | 分区筛选 |
| `keyword` | string | 空 | 匹配标题 / 摘要 |

响应 `data`：`{ total, list[] }`，`list` 条目：

```json
{
  "id": 501, "category": "setting", "title": "…", "summary": "…",
  "authorId": 2, "authorName": "林间写手",
  "status": "published", "adminRemoved": false,
  "viewCount": 233, "likeCount": 232, "commentCount": 2, "collectCount": 88,
  "createTime": "2026-10-12 19:12:00"
}
```

## 3. 帖子详情 `GET /api/admin/posts/{post_id}`

在列表字段基础上追加：

| 字段 | 说明 |
|------|------|
| `content` | 正文（读 `community/{userId}/{postId}.json`） |
| `images` | 配图 URL 列表（按 sort） |
| `tags` | 标签列表 |
| `attachment` | `{ type, meta }` 或 `null`（对话快照/角色卡/设定集/时间线视图） |
| `updateTime` | 更新时间 |

## 4. 平台下架 / 恢复 `PUT /api/admin/posts/{post_id}/status`

请求体：`{ "status": "removed" | "published" }`

- `removed`：`status='removed'` 且 **`admin_removed=1`** —— 作者侧 `POST /idea/posts/{id}/restore` 将被拦截（返回"该内容已被平台下架，如有疑问请联系管理员"），防止"平台下架后作者一键重新上架"绕过。
- `published`：`status='published'` 且 `admin_removed=0`，作者侧操作恢复原行为。
- 响应：`{ "id", "status", "adminRemoved" }`。

> `admin_removed` 为 `idea_post` 后加列（`main.py` lifespan 启动自动 `ALTER TABLE` 补列，默认 0）。

## 5. 硬删除 `DELETE /api/admin/posts/{post_id}`

**级联清理（不可恢复，前端须二次确认）**：

1. `idea_attachment` 行 + 附件文件（`delete_community_json`）
2. `idea_post_image` 行 + **本地上传配图文件**（仅清理 `/api/uploads/idea-images/` 前缀且文件名无路径分隔符/`..` 的 URL，防路径穿越；外链不动）
3. 正文文件（`delete_community_json(body_path)`）
4. `idea_comment` / `idea_like` / `idea_collect` / `idea_post_tag` 全部行
5. `idea_post` 行

## 6. 评论

**列表 `GET /api/admin/posts/{post_id}/comments?page&pageSize`** → `{ total, list[] }`：

```json
{ "id": 9001, "postId": 501, "authorId": 3, "authorName": "夜航船",
  "content": "…", "createTime": "2026-10-12 16:10:00" }
```

**删除 `DELETE /api/admin/comments/{comment_id}`**：

- 无作者限制（管理端全量可删）；
- 回写所属帖 `comment_count = max(0, count-1)` 并重算热度（`3赞+2藏+2评+1浏览`）；
- 同步 Redis 热度增量 `cache.hot_zincr(post_id, -2)`。

## 7. 灵感墙便签

**列表 `GET /api/admin/sticky?page&pageSize&keyword&done`**

- `keyword`：匹配 **用户名 / 昵称**（正文在文件中，不参与 SQL 筛选）；
- `done`：`true` / `false` / 缺省=全部。

响应 `data.list[]`：

```json
{ "id": 801, "userId": 1, "userName": "演示用户", "color": "yellow",
  "done": false, "inPool": false, "content": "…", "images": [],
  "createTime": "…", "updateTime": "…" }
```

**删除 `DELETE /api/admin/sticky/{note_id}`**：先删正文文件（`storage/sticky/{userId}/{noteId}.json`），后删 `sticky_note` 行（项目惯例）。
