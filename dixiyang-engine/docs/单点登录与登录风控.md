# Java 端：单点登录与登录风控

> 最后更新: 2026-10-06
> 总方案见根目录 [docs/单点登录与登录风控.md](../../docs/单点登录与登录风控.md)

## 需求

同一账号仅一台设备在线（顶号踢出）；10 分钟内登录 3 次后密码登录强制邮箱验证码。

## 实现要点

1. **会话号**：`app_user.session_id`（迁移脚本 `src/main/resources/db/migration_session_id.sql`，已执行）。
2. **签发**：`JwtUtils.generateToken(userId, sessionId)` 增加 `sid` claim。
3. **校验**：`Config/JwtAuthenticationFilter.java` 解出 `sid` → `selectById` 比对 `session_id`；
   - 不匹配 → 401 `{"code":401,"msg":"账号已在其他设备登录"}`
   - 无 `sid`（旧 token）→ 401 `{"code":401,"msg":"登录已失效，请重新登录"}`
4. **登录**：`AuthServiceImpl.login()` 密码通过后检查 `require_code` → 生成 UUID 覆盖写入 → 窗口计数（`RISK_WINDOW_MINUTES=10`、`RISK_LOGIN_LIMIT=3`，UTC 时间）→ 签发。
5. **风控解除**：`loginByCode(email, code)` 校验一次性验证码通过后清 `require_code`、重置窗口、顶号签发。
6. **验证码设施（本次补齐，与 Python 对齐）**：
   - `POST /auth/send-code`（60s 限流、5 分钟有效、先发信后落库）
   - `POST /auth/login-by-code`
   - `Service/EmailCodeService.java` + `Entity/EmailVerificationCode.java` + `Mapper/EmailVerificationCodeMapper.java`
   - SMTP：`application.yml` 的 `spring.mail`（占位符取环境变量）→ 缺失时 `Utils/DotEnv.java` 从项目根 `.env` 取 `SMTP_USERNAME/SMTP_PASSWORD`（`MAIL_*` 兼容）

## 已知问题

- JWT 密钥硬编码（`JwtUtils.java:13`），与 Python `.env` 密钥不一致时切换后端会全员重登（见总文档「已知问题 1」）。
- `register` 未消费前端传来的验证码 `code`（既有行为）。
- 业务路径 `permitAll`，仅对携带 token 的请求做顶号校验。
