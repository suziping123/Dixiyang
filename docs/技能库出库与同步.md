# motion-web 技能库出库与同步方案

**位置**: `docs/技能库出库与同步.md`
**日期**: 2026-09-28
**关联**: [motion-web 技能接入](./motion-web技能接入.md)

---

## 1. 需求

1. 与 GitHub 同步（拉取远程落地页、字体资源等新提交）。
2. **把 motion-web 技能从 GitHub 仓库中删除**（技能主体含数 MB gif/webp，不应占用仓库体积）。
3. **本地必须保留技能文件**，`AGENTS.md` 索引仍指向 `motion-web-main/SKILL.md`。
4. **不能让其他协作者本地的技能被 pull 删除** —— 这是本方案的核心约束。

## 2. 核心矛盾与解法

Git 语义下，"远程删除文件"必然导致协作者 `git pull` 时**工作区同名文件被删除**（Git 不区分"内容删除"与"取消跟踪"）。因此无法靠一次 `git rm` 同时满足"远程没有"与"协作者不丢"。

解法：**取消跟踪（`git rm --cached`）+ 仓库级 Hook 自动本地化**。

| 机制 | 作用 |
|------|------|
| `git rm -r --cached` | 只从索引移除，**不动工作区文件** |
| `.gitignore` | 让恢复后的文件不再被误提交 |
| `.githooks/pre-merge-commit` | 真 merge 场景：提交前若技能文件被删，从 HEAD 恢复到工作区并移出索引 |
| `.githooks/post-merge` | **fast-forward pull 场景**（最常见，不触发 pre-merge-commit）：pull 后从 git 历史恢复技能到工作区 |
| `scripts/setup-hooks.ps1` | 一次性启用 hooks（`git config core.hooksPath .githooks`） |
| `scripts/restore-skills.ps1` | 兜底：未启用 hooks 导致文件丢失时，从 git 历史一键恢复 |

Hook 逻辑统一为两步：**① 文件缺失 → `git checkout <rev> -- <path>` 恢复到工作区；② `git rm --cached` 把它移出索引**。最终效果等同于"这些文件从未被跟踪过"，Git 全程不触碰协作者的工作区副本。

## 4. 协作者操作步骤（**必读**）

```powershell
# ① 拉取代码前，一次性启用 hooks（每台机器执行一次）
powershell -ExecutionPolicy Bypass -File scripts/setup-hooks.ps1
# 等价于：git config core.hooksPath .githooks

# ② 之后正常 pull/merge，技能文件自动保留
git pull
```

若**跳过步骤 ①** 直接 `git pull`，本地 `motion-web-main/`、`.agents/`、`.trae/` 会被删除，补救：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/restore-skills.ps1
```

## 5. 已知问题 / 限制

1. **hooks 需一次性配置**：`.git/hooks` 与 `core.hooksPath` 均无法随仓库分发（Git 设计如此），这是唯一需要人工/协作者 AI 执行的步骤。已通过 AGENTS.md 规则 10 约束：协作者的 AI 助手会在会话中自动提醒并执行。
2. **全新 clone 拿不到技能**：出库后 GitHub 上没有技能文件，新成员克隆后需从原技能提供方获取，再放入 `motion-web-main/`（或运行 restore 脚本，前提是其克隆包含出库前的历史）。
3. **历史提交仍保留大文件**：按决策不做历史重写（`filter-repo`/BFG），仓库体积不变，仅 HEAD 及后续版本不再包含技能。
4. **协作者手动 `git add -A` 不会误提交**：`.gitignore` 已覆盖三个路径。
5. `git clean -fd` 会清除未跟踪的技能文件 —— 协作者不要在仓库根执行 `git clean`，或执行后用 restore 脚本恢复。

## 6. 验证方式

```powershell
# 远程不再跟踪技能（push 后执行）
git ls-tree -r origin/main --name-only | Select-String "motion-web-main|\.agents|\.trae"
# 预期：仅 docs/motion-web技能接入.md 命中，无 motion-web-main/ 等条目

# 本地文件仍在且被忽略
Test-Path motion-web-main/SKILL.md          # 预期 True
git status --short -- motion-web-main .agents .trae   # 预期：无输出

# hooks 已启用
git config --get core.hooksPath             # 预期 .githooks

# 模拟协作者 pull 后技能是否被删（启用 hooks 前提下）
git pull
Test-Path motion-web-main/SKILL.md          # 预期 True
```
