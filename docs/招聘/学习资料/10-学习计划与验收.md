# 10 · 学习计划与验收

> **目标**：8 周（40 个学习日）从"能看懂"到"能审查、能复现、能设计评测、能面试表达"。
> **投入**：工作日 2 小时 + 周末 4 小时；总计约 100-120 小时。
> **原则**：每天必须有产出（笔记/命令/测试/评审），不能只阅读。

---

## 1. 前置条件

### 1.1 环境

- Python 3.11+、uv；
- Node `^20.19` 或 `>=22.12`；
- MySQL 8（Docker 或本机）；
- Redis 可选；
- Docker（P10/部署验证）；
- 浏览器 + DevTools；
- 可选：Playwright、Java 17/Maven。

### 1.2 账号与数据

- 测试账号 `admin123 / 123456`；
- 真实登录，禁伪造 token；
- 注意 10 分钟 3 次密码登录触发验证码；
- 不要读取/提交真实 `.env`；
- 准备测试小说/章节/便签数据，避免污染真实数据。

### 1.3 工具

```bash
git status
curl
jq（可选）
docker compose
node --version
uv --version
```

## 2. 学习节奏

### 2.1 每日 2 小时模板

| 时间 | 内容 | 产出 |
|---|---|---|
| 40 min | 读一卷的一节 | 3-5 条要点 |
| 40 min | 动手：命令/代码/复现 | 命令记录/截图/测试 |
| 20 min | 自测：合上书回答 | 错题/缺口 |
| 20 min | 写笔记：原理+项目+追问 | 一页 Markdown |

### 2.2 每周节奏

- 周一至周五：每天 1 节 + 练习。
- 周六：项目实操/复现 2-3 小时。
- 周日：复盘 + 周测 + 补缺口 1-2 小时。

### 2.3 笔记模板

```markdown
## 主题
## 一句话解释
## 机制/流程
## 项目证据（文件/接口/日志）
## 常见错误
## 我的疑问
## 面试怎么讲（60 秒）
```

## 4. 每日练习清单

### 4.1 前端

- [ ] 用 375 视口打开一个页面，检查溢出/双列/弹窗。
- [ ] 抓一个真实请求，核对 HTTP 状态 + 业务码 + 页面表现。
- [ ] 找一个异步回调，判断是否有竞态/取消。
- [ ] 检查一个列表的 key/空态/错误态。
- [ ] 复现一个 CSS 层叠/毛玻璃问题。

### 4.2 后端

- [ ] 找一个接口，画出鉴权/参数/事务/响应链路。
- [ ] 检查是否有 owner 校验/路径拼接/上传限制。
- [ ] 用一个坏输入触发 4xx，确认错误结构。
- [ ] 检查一个 async 路由是否有阻塞调用。
- [ ] 看一条日志，确认是否有 request_id/脱敏。

### 4.3 RAG

- [ ] 查一次集合 count/peek。
- [ ] 记录一次召回的 topN 原文/分数。
- [ ] 检查 rerank 是否真的调用成功。
- [ ] 检查引用是否来自检索结果。
- [ ] 写一条评估样例（query/相关文档/要点）。

### 4.4 Agent 评测

- [ ] 读一条轨迹，找第一个错误决策。
- [ ] 判断是否有硬编码/删测试/伪造输出。
- [ ] 给一个任务写 3 条隐藏测试。
- [ ] 写一个 Rubric 档位。
- [ ] 计算一个指标的样本量/边界。

### 5.1 第 2 周验收（前端）

## 8. 模拟考安排

### 8.1 笔试模拟

- 限时 90 分钟；A/B/C/D/E 选做。
- 不查资料；先写关键词再展开。
- 交卷后按题库评分表自评。
- 错题当天归因，3 天后重做。

### 8.2 实操模拟

- 60 分钟：启动→复现→取证→修复/建议。
- 必须交：命令、请求/响应、日志、根因、回归。
- 不允许"重启好了"作为结论。

### 8.3 面试模拟

- 3 分钟项目 + 20 分钟追问。
- 录音回听：结构/证据/取舍/边界。
- 不会的问题用"理解→验证→风险"回答。
