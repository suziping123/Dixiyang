> **定位**：把容易混、容易说错、容易被追问的点集中成速查表；用于复习、面试前自测、评审时统一口径。
> **层级**：L2-L7
> **用法**：先盖住右列自答，再对照；不要背句子，背"判断依据 + 项目例子"。


> **来源约定**：未标来源的段落为通用技术知识；标 `[项目]` 的有仓库代码/脚本/文档依据；`[项目-冲突]` 表示材料互相矛盾；`[推断]`/`[待确认]` 表示分析或尚需验证。

## 1. 核心概念对照表

### 1.1 JavaScript / TypeScript

| 概念 A | 概念 B | 关键区别 | 一句话判断 |
|---|---|---|---|
| `var` | `let/const` | 函数作用域 vs 块作用域；提升行为不同 | 循环闭包/块级隔离用 let |
| `==` | `===` | 是否做类型转换 | 业务比较统一 `===`，仅 `== null` 兼容空值 |
| `null` | `undefined` | 主动空值 vs 未赋值/缺失 | 接口缺字段常是 undefined；显式空用 null |
| `const` | 不可变 | 绑定不可变，对象内容可变 | `const` 不等于 freeze |
| 浅拷贝 | 深拷贝 | 是否递归复制嵌套引用 | 嵌套修改会互相影响 |
| 闭包 | 普通函数 | 是否捕获外部作用域变量 | 捕获的是变量绑定，不是快照 |
| `this` | 箭头函数 | 动态绑定 vs 词法绑定 | 回调里想用外层 this 用箭头 |
| `Map` | 普通对象 | 键类型/顺序/原型污染 | 非字符串键/频繁增删用 Map |
| `Set` | 数组 | 去重/成员判断 | 对象去重按引用，不按内容 |
| `unknown` | `any` | 是否强制收窄 | 外部数据用 unknown + 校验 |
| `interface` | `type` | 可扩展/联合/映射类型能力 | 对象形状用 interface，联合/工具类型用 type |
| 类型断言 `as` | 运行时校验 | 是否真的检查 | `as` 只是编译器承诺 |

### 1.2 Vue3

| 概念 A | 概念 B | 关键区别 | 适用 |
|---|---|---|---|
| `ref` | `reactive` | 任意类型/`.value` vs 仅对象/直接属性 | 基本类型/整体替换用 ref |
| `computed` | `watch` | 派生值/缓存 vs 副作用 | 派生数据用 computed |
| `watch` | `watchEffect` | 显式依赖 vs 自动收集 | 依赖明确用 watch |
| `v-if` | `v-show` | 销毁重建 vs display | 频繁切换用 v-show |
| `v-model` | `:value + @input` | 语法糖 vs 手动 | 表单双向绑定 |
| `key` | index | 稳定身份 vs 位置 | 列表用唯一 ID |
| `keep-alive` | 普通卸载 | 缓存实例 vs 销毁 | 需要保留状态 |
| `nextTick` | `setTimeout` | DOM 更新后 vs 宏任务 | 拿更新后 DOM 用 nextTick |
| `shallowRef` | `ref` | 只跟踪引用 vs 深层 | 大对象/第三方实例 |
| `markRaw` | `reactive` | 跳过代理 vs 响应式 | ECharts/类实例 |

### 1.3 浏览器/网络

| 概念 A | 概念 B | 关键区别 |
|---|---|---|
| Cookie | localStorage | 自动携带/可 HttpOnly vs 手动读取/易受 XSS |
| localStorage | sessionStorage | 持久 vs 会话级 |
| 强缓存 | 协商缓存 | 不发请求 vs 304 复用 |
| CORS | CSRF | 跨域读取限制 vs 借用 Cookie 发请求 |
| XSS | CSRF | 注入脚本 vs 伪造请求 |
| 401 | 403 | 未认证 vs 已认证无权限 |
| 404 | 403 伪装 404 | 不存在 vs 隐藏存在性 |
| SSE | WebSocket | 单向/HTTP vs 双向/协议升级 |
| GET | POST | 读取/幂等/可缓存 vs 创建/非幂等 |
| PUT | PATCH | 全量替换 vs 部分更新 |
| REST | RPC | 资源 vs 动作 |
| 防抖 | 节流 | 停止后执行 vs 固定频率 |
| 回流 | 重绘 | 几何布局 vs 颜色绘制 |

### 1.4 后端/数据库

| 概念 A | 概念 B | 关键区别 |
|---|---|---|
| 进程 | 线程 | 地址空间/资源 vs 共享进程资源 |
| 并发 | 并行 | 重叠推进 vs 同时执行 |
| 协程 | 线程 | 用户态调度/轻量 vs 内核调度 |
| GIL | 锁 | 全局解释器锁 vs 具体临界区 |

| 乐观锁 | 悲观锁 | 提交时检查版本 vs 先锁再操作 |
| 索引 | 主键 | 加速查询结构 vs 唯一标识 |
| N+1 | join | 循环查询 vs 一次关联 |
| offset 分页 | cursor 分页 | 跳过 N 行 vs 从游标继续 |

| Redis | MySQL | 内存缓存/易失 vs 持久关系库 |

### 1.5 RAG / LLM

| 概念 A | 概念 B | 关键区别 |

| LLM judge | 人工评分 | 便宜可扩展 vs 贵但可靠 |

### 1.6 评测/工程

| 概念 A | 概念 B | 关键区别 |
|---|---|---|
| 单测 | 集成测试 | 隔离逻辑 vs 真实依赖/契约 |
| 集成 | E2E | 接口/DB vs 真实用户路径 |

## 2. 常见错误与反例

### 2.1 前端

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只看 HTTP 200 | 业务失败当成功 | 检查 `code` + `unwrap` |
| 403 当 401 | 误登出 | 区分状态码 |
| 用 index 作 key | 列表错位 | 稳定 ID |
| 请求不取消 | 竞态覆盖 | 序号/Abort |
| 卸载不清理 | 泄漏/报错 | `onUnmounted` |
| 直接改 props | 数据流混乱 | emit |
| `reactive` 整体替换 | 失去响应式 | `Object.assign`/ref |
| `computed` 里发请求 | 重复请求 | watch/显式调用 |
| 移动端只缩放 | 体验差 | 响应式 + 真机 |
| 只跑 build 不 preview | base/代理错 | preview + 真机 |
| 用 `localStorage.clear()` | 清掉其他数据 | 只删本应用键 |
| 中文输入只监听 Enter | 选词误发送 | composition + isComposing |

### 2.2 后端

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只认证不校验归属 | IDOR | owner/role |
| 路径直接拼接 | 路径穿越 | resolve + 根目录 |
| 上传先读内存再校验 | OOM | 流式 + 大小限制 |
| 业务失败返回 200 | 监控失真 | 状态码 + 业务码 |
| 无超时/无重试边界 | 雪崩 | 超时 + 退避 + 幂等 |
| async 里跑同步 DB | 事件循环阻塞 | 异步/线程池 |
| 先删缓存再 commit | 增量丢失 | 提交后删 |
| 先查再插防重复 | 竞态 | 唯一约束 |
| 长事务包外部调用 | 锁等待 | 缩短事务 |
| 裸 `except` | 吞错 | 具体异常 + 日志 |
| 错误响应带堆栈/SQL | 泄露 | 统一错误 |
| 无迁移/无回滚 | 变更失控 | 版本化迁移 |

### 2.3 RAG/Agent

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 换 embedding 不重建 | 检索错乱 | 全量重建 |
| 距离度量不一致 | 分数不可比 | 建库/查询一致 |
| 只看 topK 不看原文 | 误判检索 | 看 topN 原文/分数 |
| rerank 失败静默 | 质量下降无感 | 指标/告警 |
| 引用不校验 | 引用幻觉 | source_id 校验 |
| 权限只在前端 | 数据泄漏 | 检索前过滤 |
| 只看最终答案 | 过程造假 | 轨迹 + 工具日志 |
| 删测试/改断言 | 假绿 | 测试只读/审计 |
| 硬编码测试输入 | 过拟合 | 隐藏/随机测试 |
| 只报最好一次 | 误导 | 全样本/重试策略 |

## 3. 面试表达框架

### 3.1 通用三段式

```text
原理（是什么/为什么）
→ 项目证据（文件/接口/日志/数字）
→ 取舍与边界（替代方案/限制/演进）
```

### 3.2 讲缺陷

```text
现象 → 复现 → 取证 → 根因 → 修复 → 回归 → 反思
```

**加分**：说清楚"怎么排除错误假设"，而不只是"最后改了哪行"。

### 3.3 讲方案

```text
目标/约束 → 方案 A/B → 对比维度 → 选择 → 风险/降级
```

**避免**：只说"用了 X 所以好"；要给数据/条件。

### 3.4 讲评测

```text
评什么能力 → 任务设计 → 环境/Harness → 评分标准
→ 一致性/反作弊 → 指标 → badcase → 迭代
```

### 3.5 讲项目（3 分钟）

1. 一句话业务价值；
2. 架构与数据流；
3. 两个技术难点；
4. 一个真实缺陷案例；
5. 取舍与反思。

### 3.6 不会的问题

```text
"这块我没有直接做过。我的理解是 ___；如果要做，我会先验证 ___，
用 ___ 指标判断；风险在 ___。"
```

不要编造项目经验；把未知转成可验证的方案。

## 5. 陷阱清单（面试/评审）

### 5.1 说法陷阱

| 错误说法 | 问题 | 更好说法 |
|---|---|---|
| "用了 Redis 所以快" | 没有命中率/分位数 | "P95 从 1.8s 降到 0.37s，命中 99.99%，但测试是小数据集" |
| "用了 JWT 所以安全" | 无撤销/越权讨论 | "JWT + sid 顶号 + 资源归属校验" |
| "测试全绿" | 可能弱断言/删测试 | "隐藏测试 + 回归 + 断言副作用" |
| "覆盖率 90%" | 不代表质量 | "关键路径/错误分支覆盖" |
| "Agent 说完成了" | 自述不可信 | "工具日志 + 测试结果 + diff" |
| "RAG 效果不错" | 无指标 | "golden set 上 Recall@5/faithfulness" |
| "这是框架 bug" | 无证据 | "最小复现 + 版本 + 对照" |
| "重启好了" | 无根因 | "定位到 X，修复 Y，回归 Z" |

### 5.2 逻辑陷阱

- 相关不等于因果：清缓存后好了，可能是重启/数据变化。
- 单次成功不等于稳定：并发/边界/长跑。
- 小数据集压测不能外推生产容量。
- 平均值掩盖长尾：看 P95/P99。
- 通过测试不代表需求正确：测试 oracle 可能错。
- 结果对但过程造假：必须看轨迹。

### 5.3 评测陷阱

| 陷阱 | 后果 | 对策 |
|---|---|---|
| 任务泄题 | 分数虚高 | 不公开答案/定期换题 |
| 测试可改 | 删断言 | 测试只读/独立副本 |
| 硬编码 | 过拟合 | 随机/隐藏用例 |
| 只评最终答案 | 忽略过程 | 轨迹 + 工具日志 |
| 评者偏差 | 不一致 | 双盲/校准/Kappa |
| 样本太少 | 结论不稳 | 样本量/置信区间 |
| 只报成功 | 误导 | 全样本/失败分布 |
| 环境不一致 | 不可比 | 固定镜像/依赖/资源 |
