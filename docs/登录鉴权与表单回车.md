# 登录鉴权与表单回车提交

> 最后更新: 2026-09-24  
> 范围: 前端 `dixiyang-vue/Dixiyang-vue3`

## 一、需求

1. **未登录不可访问业务页**：无 token / token 过期 / 脏 token 访问 `/home` 等 → 跳转 `/login`。
2. **接口 401 统一处理**：后端 HTTP 401 或业务码 401 → 清登录态 → 跳 `/login`。
3. **表单回车**：
   - 多输入框：回车**跳到下一个**输入框（账户 → 密码）。
   - 最后一个输入框：回车**触发主按钮**（登录/注册/创建/保存）。
   - 危险操作（删除确认）：回车**不**触发。

## 二、登录态

| 文件 | 职责 |
|------|------|
| `src/utils/auth.ts` | `isTokenValid()` 解 JWT `exp` 本地校验；`clearAuth()` 只清登录相关 key |
| `src/utils/http.ts` | 响应拦截：业务 `code===401`、HTTP `status===401` → `handleUnauthorized()` |
| `src/router/index.ts` | 路由 `meta.requiresAuth` + `beforeEach` 校验；无效则清 token 跳登录 |
| `src/main.ts` | 启动清理脏 token（`"undefined"`/`"null"`）及过期 token |

**双层策略**：本地 `exp` 校验（拦截明显无效）+ 401 兜底（服务端拒绝）。

跳转使用 `window.location.href = '/login'`，避免 http 模块与 router 循环依赖；模块级 `redirectingToLogin` 防重复。

## 三、回车提交（核心）

### 根因（曾失效）

模板写法：

```vue
@keyup.enter="enterSubmit(handleLogin)"
```

Vue 编译为：`withKeys($event => enterSubmit(handleLogin), ["enter"])`  
→ 只**创建**包装函数，**不调用**返回的处理器 → 业务永远不执行。

### 正确用法

```vue
@keyup.enter="enterSubmit(handleLogin, $event)"
```

编译为：`withKeys($event => enterSubmit(handleLogin, $event), ["enter"])` → **立即执行**。

### 工具实现 `src/utils/enterSubmit.ts`

1. 焦点在 `textarea` / `select` / 按钮 / `.el-select` / `[role=button|combobox]` → 不处理。
2. 容器内还有下一个可见输入框 → `focus()` 下一框并全选。
3. 已是最后一框 → 调用提交函数 `fn()`。

容器查找：`form`、`.el-form`、`.creating-card`、`.settings-wrapper`、`.dialog-right`。

### 覆盖位置

| 场景 | 文件 | 行为 |
|------|------|------|
| 登录 | `LoginView.vue` | 用户名 → 密码 → 提交 |
| 注册 | `LoginView.vue` | 昵称 → 姓名 → 邮箱 → … → 提交 |
| 创建/编辑角色 | `CharacterManagerView.vue` | 逐框跳转 → 保存 |
| 新建时间线 | `TimelineView.vue` | 名称 → 描述(跳过) → 创建 |
| 新建事件 | `TimelineView.vue` `creating-card` | 逐框 → 保存 |
| 设置昵称/邮箱 | `SettingsView.vue` `form.account-form` | 昵称 → 邮箱 → 保存 |
| 封面 URL | `NovelPageHeader.vue` | 单框直接 `saveCover` |
| 创建小说 | `CreateCard.vue` | 原生 `form + submit`，浏览器默认回车提交 |
| 聊天发送 | `RagAssistantView.vue` | 已有 `@keydown.enter` 发送，Shift+Enter 换行 |

### 危险操作

- `src/utils/confirm.ts`：`ElMessageBox.confirm` 设 `autofocus: false`，回车不默认确认删除。
- 自定义删除 `el-dialog`：焦点在容器，确认按钮不自动聚焦，无需改。

## 四、关联修复

- `HomeView.fetchNovels`：`code!==200 || !data` 提前返回；`Array.isArray` 兼容数组/分页。
- 401 时调用方 `catch` 静默即可，跳转由拦截器统一处理。

## 六、手动验收清单

1. 清空 localStorage 访问 `/home` → `/login`。
2. 登录页：用户名回车跳密码，密码回车触发登录。
3. 注册页：各字段回车逐框前进，最后一框触发注册。
4. 创建角色 / 新建时间线 / 新建事件：同上。
5. 设置：昵称回车跳邮箱，邮箱回车保存。
6. 封面 URL 回车保存。
7. 删除确认弹窗：回车不删除。
