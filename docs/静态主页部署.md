# 静态主页 GitHub Pages 公网部署

## 需求

- 把项目静态主页（落地页 `/`，`LandingView.vue`）**公网部署到 GitHub Pages**。
- 仓库：`github.com/suziping123/Dixiyang`（公开），落地页即 SPA 首页，免登录。

## 线上地址

```
https://suziping123.github.io/Dixiyang/
```

- 落地页 = `/`；深链（如 `/Dixiyang/ideas`）由 `404.html` 兜底回 SPA，Vue Router catch-all 接管。
- **后续更新**：push `main` 自动重新构建发布（无需手动）。

## 方案

GitHub Actions 自动部署（`.github/workflows/deploy-pages.yml`）：

1. 触发：push `main` + 手动 `workflow_dispatch`
2. build job：checkout → Node 22 + npm 缓存 → `npm ci` → `vite build --base=/Dixiyang/` → `cp index.html 404.html`（SPA 兜底）→ 上传 artifact
3. deploy job：`actions/deploy-pages@v4` 发布

要点：

- `--base=/Dixiyang/` **只在 CI 注入**，不改 `vite.config.ts`，本地 dev/build 不受影响（项目页路径为 `/仓库名/`）。
- build 用 `build-only`（跳过 type-check），部署不被类型告警阻塞。
- 一次性手动设置（已完成）：Settings → Pages → Source = **GitHub Actions**（下拉框选完即保存，无 Save 按钮）。

## 排障：CI build 失败根因（首轮）

- **症状**：workflow 首跑 build job 失败；本地 `vite build` 却通过。
- **根因**：`LoginView.vue` 引用的背景视频 `src/assets/videos/卡比.mp4` 被 `.gitignore:132` 的 `*.mp4` 忽略、从未提交 → CI 干净 checkout 后文件不存在 → `[vite:asset] Could not load`。
- **复现法**（定位关键）：`git worktree add <temp> HEAD` 拉干净代码 + junction 复用 node_modules → 本地必现，即可与 CI 对齐。
- **修法**：`git add -f` 提交该视频（32.4 MB < GitHub 100 MB 单文件限制）；用户确认选此方案（另一选项为缺文件时降级隐藏 `<video>`）。
- **教训**：本地能 build ≠ CI 能 build——工作区 WIP 与未跟踪/被忽略文件是差异源。

- API 观测：`GET /repos/suziping123/Dixiyang/actions/runs` 轮询 run 状态；日志需 admin 权限匿名拿不到，用本地 worktree 复现排障。

## 已知问题

- `index.html` 的 `og:image`/`og:url` 仍为相对值，需补绝对地址 `https://suziping123.github.io/Dixiyang/...`（见 `落地页介绍页.md`）。
- 单 JS chunk 9.4 MB（gzip 5.7 MB），首次加载偏慢；后续可 `manualChunks` 分包 + 媒体外置。
- 线上仅静态前端：登录后功能需主后端（8084）API，静态站上会请求失败——预期内（本轮只发布免登录落地页）。

## 维护

- 日常：正常 push `main` 即自动发布。
- 手动重发：Actions 页 → "Deploy to GitHub Pages" → Run workflow。
- 回滚：revert 提交后 push，或在 Actions 选择历史成功 run 重跑。
