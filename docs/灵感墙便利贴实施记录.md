## 1. 需求回顾

- **美术风格**：拟物便利贴（纸纹、卷角、图钉、投影、微旋转），钉在页面上可四处移动
- **核心交互**：
  - 浮动态：全站悬浮可见，可任意拖动
  - 钉住态：点图钉钉在当前路由，仅该路由显示、锁定不可拖动；再点图钉解锁回浮动
  - **投喂 AI 补全**：把便签拖进右下「📮 素材池」→ 写小说时在「AI 补全」面板勾选带上
- **不分类**：靠颜色（5 色）+ 搜索框 + 空间位置梳理
- **上传图片**：便签支持最多 6 张图（MD5 去重）
- **专用页面**：`/inspiration` 灵感墙（软木板背景、新建、搜索、素材池窗口）
- **拟物动效**：钉入/拔钉弹跳、拿起放大、投喂呼吸、便签落下 settle

## 4. 已知问题与缓解

| 问题 | 缓解 / 备注 |
|------|-------------|
| 便签坐标存 %，极端窄屏（<320px）可能被夹紧 | 显示时 `clamp(0, max)` 兜底，移动端 `noteSize=144px`、右避让 64px（FAB） |
| 钉住后切换路由便签消失（符合预期），但用户可能困惑"哪去了" | 首次引导卡片 + 图钉 tooltip 明确语义；可再加"我的钉住便签"列表（二期） |
| `inPool=true` 的便签仍在墙上（盖"已投喂"章），未物理移除 | 设计为"复制进池"，防误删；池里可"取回"置 `inPool=false` |
| 搜索非匹配便签仅降透明度（不隐藏），钉住语义不破坏 | `opacity:0.22 + saturate(0.4)`，保留位置与图钉状态 |
| 图片上传复用现有 MD5 去重，不同用户同图复用同一文件 | 符合 AGENTS §7，无额外存储成本 |
| 移动端 FAB 右锚 74px（球 46+右缘 14），素材池 `margin-right:64px` 让开 | 已按 AGENTS 移动端规则精算 |
| `pointer-events:none` 父层导致子组件拖动失效（曾卡 3 轮） | `.sticky { pointer-events: auto }` 显式恢复，**文档化防回归** |

## 7. 关键技术细节备忘（防踩坑）

1. **坐标归一化**：存 `x,y ∈ [0,1]`（相对视口），显示时 `x*vw, y*vh` 再 `clamp`。避免 resize/全屏切换导致漂移。
2. **父层 `pointer-events:none` 子层必须显式 `auto`**：否则合成/原生指针事件全不进子组件，`click()` 程序触发能过但真拖动过不去。
3. **拖动监听挂 `window` 而非元素**：`pointermove/up` 在光标移出元素时仍触发，合成事件更稳；卸载时 `removeEventListener` 兜底。
4. **FAB 右锚 74px（球 46+右缘 14）**：页面/弹窗/池窗右避让 `64px`（14+46+4 缓冲），375 下内容 311px、双列 `minmax(140px)` 刚好放下。
5. **弹窗/全局输入蒙板（坑2）**：便签编辑态 `textarea` 在 `.el-dialog` 外（fixed 层），不受 `main.css` 三条规则影响；若未来移入弹窗需补 CSS。
6. **补全上下文截断**：`[灵感]` 段单条 ≤300 字、总设定 ≤1500 字，防 token 爆炸。
7. **首次引导只出现一次**：`localStorage.stickyGuideDone='1'` 永久关闭。
