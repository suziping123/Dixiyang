## 1. 需求回顾

- **美术风格**：拟物便利贴（纸纹、卷角、图钉、投影、微旋转），钉在页面上可四处移动
- **核心交互**：
  - 浮动态：全站悬浮可见，可任意拖动
  - 钉住态：点图钉钉在当前路由，仅该路由显示、锁定不可拖动；再点图钉解锁回浮动
  - **投喂 AI 补全**：把便签拖进右下「📮 素材池」→ 写小说时在「AI 补全」面板勾选带上
- **不分类**：靠颜色（5 色）+ 搜索框 + 空间位置梳理
- **上传图片**：便签支持最多 6 张图（MD5 去重）
- **专用页面**：`/inspiration` 灵感墙（软木板背景、新建、搜索、素材池窗口）
- **拟物动效**：钉入/拔钉弹跳、拿起放大、投喂呼吸、便签落下 settle

## 7. 关键技术细节备忘（防踩坑）

1. **坐标归一化**：存 `x,y ∈ [0,1]`（相对视口），显示时 `x*vw, y*vh` 再 `clamp`。避免 resize/全屏切换导致漂移。
2. **父层 `pointer-events:none` 子层必须显式 `auto`**：否则合成/原生指针事件全不进子组件，`click()` 程序触发能过但真拖动过不去。
3. **拖动监听挂 `window` 而非元素**：`pointermove/up` 在光标移出元素时仍触发，合成事件更稳；卸载时 `removeEventListener` 兜底。
4. **FAB 右锚 74px（球 46+右缘 14）**：页面/弹窗/池窗右避让 `64px`（14+46+4 缓冲），375 下内容 311px、双列 `minmax(140px)` 刚好放下。
5. **弹窗/全局输入蒙板（坑2）**：便签编辑态 `textarea` 在 `.el-dialog` 外（fixed 层），不受 `main.css` 三条规则影响；若未来移入弹窗需补 CSS。
6. **补全上下文截断**：`[灵感]` 段单条 ≤300 字、总设定 ≤1500 字，防 token 爆炸。
7. **首次引导只出现一次**：`localStorage.stickyGuideDone='1'` 永久关闭。

## 8. 素材池堆叠视觉修复（2026-10-12）

### 需求
- 拖入池子的便签要视觉上"摞成一摞纸"，而不是一条压扁的玻璃条；
- hover 池子保留逐个展开，但不能有残影/持续抖动。

### 根因（实测定位）
1. **`.sc-paper` 只有模板没有样式**：堆叠卡的纸面 div 在 CSS 中无任何规则 → 渲染成透明/无高度的空壳，看起来"就一条"。
2. **`stackCardStyle()` 内联调 `Math.random()`**：hover 时 `hoverIdx` 变化触发重渲染 → 每张卡重新随机角度/位移 → 卡片每帧变换 = 残影抖动。
3. **堆叠卡与扇形展开列表同时显示**：`hoverStack` 只控制 fan-list，堆叠区不隐藏 → 同批内容出现两份 = "很多残影"。

### 方案
- `jitterMap: Map<id, {rot,x}>` 按便签 id **缓存固定随机偏移**，渲染函数只读缓存（Math.random 只在首次生成时调用）。
- 新增 `.stack-area` 包裹层同时接管 `mouseenter/leave`，内部 `v-show="!hoverStack"` 让**堆叠与展开互斥显示**，鼠标在两者间移动不跨界、不闪烁。
- 补全 `.sc-paper` 纸面样式：五色 `--paper`（yellow/pink/blue/green/purple，与墙上便签同色）+ 顶光渐变 + 横格纸纹 + 右下卷角 `::after` + 深墨色文字 `#3a3126` + 双层投影。
- 堆叠参数：`bottom: 14px` 基准、每张 `translateY(-idx*7px)`、固定 `rotate(±5°)` 错位、`transform-origin: center bottom`。
- `will-change` 收敛为只提升 `transform`（去掉 box-shadow/z-index，减少合成层闪烁）。

- `dixiyang-vue/Dixiyang-vue3/src/components/sticky/PoolWindow.vue`（模板结构 / `stackCardStyle` / 堆叠与纸面样式）

### 二轮：逻辑重做（2026-10-12，用户反馈"取回/投喂要刷新、hover 残影仍在、池内功能没用"）

**根因（实测定位 3 个确定 Bug）**：
1. **数据死快照**：`const items = store.pool` 在 setup 只取一次值，而 `store.pool` 是 computed、每次变化生成新数组 → 池子永远显示挂载时的旧数据，投喂/取回/删除必须刷新才见效。
   修：`const items = computed(() => store.pool)`。
2. **hover 抖动循环**（上一轮引入）：`v-show="!hoverStack"` 挂在 `.stack-zone`（min-height:150px）上，hover 时区域高度塌陷 → 光标下方内容换位滑出区域 → `mouseleave` → 恢复 → `mouseenter` → **堆叠/展开无限来回切换**，每次重播动画 = "残影、一直在变换"。
   修：**砍掉整个扇形展开列表**，堆叠区改为**内联绑定固定高度**（按张数计算，hover 零变化），物理上不可能循环。
3. **拖放投喂永不生效**：`elementFromPoint(便签中心)` 永远先命中拖拽中的便签自己（z 高且 `pointer-events:auto`），`.closest('[data-pool-drop]')` 永远爬不到池子。
   修：命中检测前置临时 `pointer-events: none`，测完恢复。

**池内交互重做（美术保留，功能精简）**：
- 删除：hover 扇形展开列表、`fanCardStyle`、双动画叠加（`fanIn` animation + transition-group 同时跑）、`expandId` 点击展开。
- 新交互：默认一摞纸（美术不变）；hover 时卡片**拉开间距 24px**（`stackCardStyle` 按 `hoverStack` 切换 gap，依次 25ms 错峰入场），露出每张卡上沿 → **取回/删除按钮直接浮现在卡片右上角**（`.sc-ops`，hover 卡片时显现），点完即走。
- `areaHeight` computed：`14 + (n-1)*24 + 120`（空态 90），绑定到 `.stack-area` 高度；`.stack` 改 `position:absolute; inset:0`，卡片 `bottom` 锚点恒定在区域底部。
- 墙上表现按用户拍板**不变**：投喂后便签留在墙上（工具栏 ✓ 状态已足够）。

### 四轮审查发现并修复的 3 个 Bug
1. **拖后误切换完成态**：拖拽结束浏览器补发 `click`（down/up 都落在 `.content`）→ 误触发 `toggleDone` 划掉内容。修：`suppressClick` 标记，`onPointerUp` 拖拽分支置位，`toggleDone/bringFront` 消费后复位；`setTimeout(0)` 兜底防标记残留吞掉下次合法点击。
2. **`moved` 不重置 → 单击误走拖拽逻辑**：拖过一次后 `moved` 恒 true，之后每次单击都执行「保存位置 PUT + `elementFromPoint` 命中检测」，便签悬在池口上方时**单击即误投喂**。修：`onPointerDown` 开头 `moved = false`。
3. **编辑态 `z-index: 1000 !important` 压掉置顶**：`startEdit` 已调 `bringToFront()`（topZ 递增），`!important` 强制拉回 1000，topZ 超千后编辑中便签反被盖。修：删除该规则，依赖内联 zIndex。
