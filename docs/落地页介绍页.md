# 对外介绍落地页（/ 首页）

## 需求

- 为 Dixiyang 做对外介绍页：设计感 + 动效，不显 AI 味。
- 落地页即 SPA 首页 `/`（免登录），登录页靠后；路由守卫行为不变（非 `meta.public` 页面仍拦截到 `/login`）。
- 页内含 GitHub（https://github.com/suziping123/Dixiyang）与登录入口。
- 功能展示用纯 CSS/DOM 抽象演示，不用截图；文案事实以 `docs/介绍.md` 为唯一来源。
- **v2 改版**：用户否掉 v1「墨夜编稿」长滚动 7 段风格，要求**单屏 + 索引切换**；风格按 motion-web skill 重选为「暖纸编辑部」（visual-bank p-02 Warm Cream + t-04 衬线标题×sans/mono 界面）。

## 方案

### 视觉：「暖纸编辑部」（v2）

- 纸底 `#f7f2ed` / 面板白 `#ffffff` / 次底 `#efe8e0`；墨字 `#1a1a18`（60% `#666`、40% `#999`）；强调色**红笔批注红 `#d64545`**（hover `#b83232`，accent-on `#fff8f2`）。
- 中文 display 子集化 Noto Serif SC（`NotoSerifSC-Subset.woff2`，可变轴 `font-weight: 200 900`），Latin 界面字用自托管 Space Grotesk 300/500，mono 走系统栈。
- 三层 token：`src/styles/landing/tokens.css`（primitive → semantic → component）+ 单屏布局 token（`--ld-nav-h: 58px`、`--ld-index-w`、`--ld-stage-pad`）+ 三档动效时长/缓动。
- 样式必须保持**未分层**（`main.css` 为 unlayered，会压过任何 `@layer`）。

### 结构：单屏仪表盘（Single screen instrument，page-design §1）

- `100dvh` 不滚动：顶栏 `LandingNav` + 左缘竖排章节索引 `LandingIndex`（tablist）+ 舞台 6 面板。
- 6 面板：`HeroPanel` → `ProblemPanel` → `CapabilitiesPanel` → `AssistantPanel` → `ProcessPanel` → `StartPanel`（Closing+Proof 合并），组装于 `views/LandingView.vue`；`views/NotFoundView.vue` 为 catch-all 404（自带亮纸底）。
- 面板绝对叠放，active 由 `:class="{is-active}"` 控制；inactive `visibility: hidden`（a11y）。
- **移动端 ≤768px 降级**（page-design §7）：纵向流、索引隐藏、面板 `position: static`。

### 交互与动效（GSAP，`useLandingMotion.ts`）

- 切换方式：点击索引 / 滚轮 / 键盘（↑↓/PageUp/Down 恒切换、←→ 仅非按钮焦点、Home/End）；转场 `locked` 锁防惯性连发。
- 签名转场「抽稿换页」：旧稿上移微旋抽走、新稿自下叠上；进入时 `[data-ld-in]` stagger + `[data-counter]` count-up。
- 面板内动效：助手打字机（750ms thinking → 34ms/2字符，isActive 触发，移动端挂载即跑）、语料墙检索 beam、hero 章节阶梯。
- 门控：`gsap.matchMedia('(min-width: 769px) and (prefers-reduced-motion: no-preference)')` 才接管；其余场景靠 CSS `is-active` 静态完成态。GSAP inline autoAlpha 结束后 `clearProps` 交还 CSS。
- 无障碍：`role=tablist/tab` + `role=tabpanel`、focus 跟随 active 面板。

### 路由

- `/` → `LandingView`（`meta: { public: true, title: ... }`）；catch-all → `NotFoundView`（public）。
- 守卫为 `to.meta.public` 白名单放行；`document.title` 随路由。
