## 1. 概述与范围

### 1.1 一句话

「点子库」= **私有点子草稿 + 公开创意社区（帖子）**，支持把与 AI 的对话以**只读快照卡片**附在帖子里交流，附带点赞/评论/收藏/标签/热门排序。

### 1.2 MVP 范围（第一期做）

| 能力 | 说明 |
|------|------|
| 私有草稿 | 标题、正文、标签；增删改查、关键词搜索 |
| 发布 | 草稿 → 独立公开帖子（发布前**快照预览**确认） |
| 对话快照 | 发布时把对话链复制为只读快照文件，帖内展开卡片查看 |
| 广场 | 帖子流：热门/最新/点赞排序、标签筛选、关键词搜索、分页 |
| 互动 | 点赞（toggle）、平铺评论、收藏（灵感夹）、浏览计数 |
| 我的 | 我的帖子（可编辑/下架）、我的收藏、我的点赞记录 |

### 1.3 非目标（第一期明确不做）

- 内容审核/敏感词过滤（仅登录用户可见，先依赖登录态约束）
- 关注、私信、@、楼中楼回复
- 帖子配图/封面（后续迭代，预留字段位）
- 通知系统（被赞/被评提醒）
- ES/向量搜索（量级用 LIKE 足够，不提前引入）
- Java 侧（dixiyang-engine）同步实现——**仅 Python FastAPI 单栈**

### 1.4 技术栈与依赖

- 后端：**Python FastAPI**（用户/会话/对话链/文件存储同栈，零跨服务调用）
- DB：MySQL（SQLAlchemy 模型，`Base.metadata.create_all` 自动建新表）
- 缓存：**Redis**（计数、热门 ZSET、频控）
- 前端：Vue3 + Element Plus（沿用现栈）
- ⚠️ **实施前置**：
  1. `requirements.txt` 增加 `redis` 并 `pip install redis`（当前 venv 未装 redis-py）
  2. 探测 `REDIS_URL`（config.py 默认 `redis://localhost:6379/0`）服务可用性
  3. Redis 不可用时功能降级策略见 §4.5

## 2. 产品方案

### 2.1 双空间模型

```
我的点子库（私有）                         广场（公开）
┌─────────────────┐    发布(快照)    ┌─────────────────┐
│ 草稿 draft      │ ───────────────▶ │ 帖子 post       │
│ 标题/正文/标签   │   一对一、独立    │ 标题/正文/标签   │
│ 可关联AI对话     │   发布后互不影响  │ +对话快照卡片    │
└─────────────────┘                  │ +点赞/评论/收藏  │
                                     └─────────────────┘
```

- **发布 = 生成独立帖子**：发布后草稿继续可改（改了再发=新帖子）；帖子在「我的帖子」里独立编辑，两者数据不联动。
- **关联对话可选**：发布时可从「我的会话列表」选一次对话 → 复制为快照；不选则纯文字帖。

### 2.2 对话快照（只读）设计

- 发布时把对话链文件（`storage/chat/{userId}/{sessionId}/*.json` 链）**复制**为：
  `storage/community/{userId}/{postId}/snapshot.json`
  结构：`{ "sourceSessionId": "...", "messages": [{role, content}, ...] }`
- DB 只存引用：`snapshot_path = "__file__:community/{userId}/{postId}/snapshot.json"`（沿用 `__file__:` 约定，`StorageService` 读取）
- **发布前预览**：PublishDialog 展示快照全文（可滚动），用户确认后才落库发布
- **隐私边界**：快照是发布时刻的副本 —— 原对话后续删除/编辑**不影响**已发布快照；发布后帖子编辑**不能**再换快照（重新发布才能换，避免审查漏洞）
- 只读：其他用户只能查看，无任何写入口
- 展示：帖内折叠卡片「📎 关联对话（N 轮）」，点击展开逐轮（user 右/AI 左，复用聊天气泡样式简化版）

### 2.3 页面与入口

**新路由** `/ideas` → `IdeaLibraryView.vue`

```
/ideas
├── Tab 1 广场（默认）
│   ├── 顶部工具条：搜索框 | 排序切换[热门/最新/最多点赞] | 标签横向筛选(可多选)
│   ├── 帖子卡片流（分页）：标题/摘要(200字)/作者/标签/时间/❤N 💬N ⭐N /「对话快照」角标
│   └── 点卡片 → 详情（路由 /ideas/post/:id，或弹窗 MVP 用弹窗）
├── Tab 2 我的点子（私有草稿）
│   ├── [新建点子] 按钮 → 编辑器（弹窗：标题/正文textarea/标签输入/关联对话下拉可选）
│   └── 草稿卡片：标题/摘要/更新时间/[编辑][发布][删除]
├── Tab 3 我的（子页签：我的帖子 / 收藏 / 点赞过）
│   └── 我的帖子卡片：[编辑][下架][查看数据]
└── 右下悬浮 [✏️ 写点子]（任意 Tab 可见）
```

**帖子详情（弹窗）**：标题/作者/时间/标签/正文（markdown 纯文本渲染，白名单有限换行加粗）/快照卡片/互动条(❤💬⭐)/评论列表(平铺+输入框)

**入口**：
1. 首页（HomeView）导航卡片/顶栏加入口「点子库」
2. FloatingNav 增加 `/ideas` 项
3. （P3 可选）RAG 助手会话头部「分享到点子库」快捷键 → 带 sessionId 跳 `/ideas?share=<sessionId>`

### 2.4 交互细节约定

- 所有写操作按钮需登录；未登录点入口 → 跳 `/login`
- 点赞/收藏为 **toggle**（再点取消），前端乐观更新 + 失败回滚
- 浏览数：**详情打开 +1**（同用户同帖子 10 分钟内去重，Redis SETNX）
- 评论删除：作者本人或（一期不做管理员）删除自己评论
- 下架 = `status=removed`，广场不可见、他人 404，作者"我的帖子"可见可重新上架
- 频控（Redis）：发帖 ≥1 条/10 秒、评论 ≥1 条/15 秒，超限返回 `code!=200`

## 3. 数据模型（MySQL / SQLAlchemy）

> 位置：`DixyangFast/src/dixiyang/models/idea.py`（新文件）
> 长文本（帖子正文、草稿正文、快照）存文件，DB 只存路径/摘要/计数。

### 3.1 `idea_post` 帖子表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int PK | 自增 |
| user_id | int idx | 作者 |
| title | varchar(200) | 标题（列表展示，DB 直存） |
| summary | varchar(300) | 正文截断摘要（列表/搜索用） |
| body_path | varchar(255) | `__file__:community/{uid}/{pid}.json`（{title, content, tags}） |
| snapshot_path | varchar(255) NULL | `__file__:community/{uid}/{pid}/snapshot.json` |
| snapshot_rounds | int default 0 | 快照轮数（卡片角标用，0=无快照） |
| tags | varchar(500) | 逗号分隔标签（如 `玄幻,系统流`），列表筛选用 LIKE |
| status | varchar(16) default `published` | `published` / `removed` |
| view_count / like_count / comment_count / collect_count | int | 冗余计数（Redis 定时回写） |
| hot_score | bigint default 0 | 热门分（Redis ZSET 同步，回源排序用） |
| created_at / updated_at | datetime | |

### 3.2 `idea_draft` 私有草稿表

| 字段 | 类型 | 说明 |
|------|------|------|
| id / user_id | | PK / 作者 |
| title | varchar(200) | |
| summary | varchar(300) | |
| body_path | varchar(255) | `__file__:community/{uid}/draft_{did}.json` |
| tags | varchar(500) | |
| source_session_id | varchar(64) NULL | 可选关联的 AI 会话（**存 sessionId 引用**，发布时才复制快照） |
| created_at / updated_at | | |

> 注意：草稿阶段只存 sessionId **引用**不复制快照 —— 用户可能继续聊、改对话，发布时刻才是想要的版本。

### 3.3 互动表

```sql
idea_like     (id, user_id, post_id, created_at, UNIQUE(user_id, post_id))
idea_collect  (id, user_id, post_id, created_at, UNIQUE(user_id, post_id))
idea_comment  (id, post_id, user_id, content varchar(2000), created_at)  -- 短文本直接入 DB，平铺无楼中楼
```

### 3.4 文件存储布局（遵守 AGENTS §7）

```
uploads/storage/community/{userId}/
├── draft_{draftId}.json          # 草稿正文 {title, content, tags}
├── {postId}.json                 # 帖子正文 {title, content, tags}
└── {postId}/
    └── snapshot.json             # 对话只读快照 {sourceSessionId, messages[]}
```

删帖子/草稿 → 同步删对应文件目录（`StorageService` 删除后 DB 删行）。

## 4. Redis 设计

### 4.1 Key 一览

| Key | 类型 | 用途 | 写入时机 |
|-----|------|------|---------|
| `idea:cnt:like:{postId}` | STRING | 点赞数缓存 | like toggle → INCR/DECR |
| `idea:cnt:collect:{postId}` | STRING | 收藏数 | collect toggle |
| `idea:cnt:comment:{postId}` | STRING | 评论数 | 评论增删 |
| `idea:view:{postId}` | STRING | 浏览数（未回写） | 详情浏览 INCR（去重窗口） |
| `idea:view:dedup:{postId}:{userId}` | STRING(SETEX 600) | 浏览去重 10 分钟 | 详情浏览 |
| `idea:hot` | ZSET | 热门榜 member=postId score=hot | 事件 ZINCRBY（见 4.2） |
| `idea:rate:post:{userId}` / `idea:rate:cmt:{userId}` | STRING(SETEX) | 发帖/评论频控 | 写接口检查 |
| `idea:cnt:flush:ts` | STRING | 上次计数回写 DB 时间戳 | 定时任务 |

### 4.2 热门分算法

```
hot = 3*like + 2*collect + 2*comment + 1*view   （朴素线性，无时间衰减；量大再迭代）
```
- 事件发生 → `ZINCRBY idea:hot {delta} {postId}`
- 列表「热门」排序 → `ZREVRANGE` 取页（配合 DB 过滤 status/tags）
- 冷启动/Redis 空 → 回源 `ORDER BY hot_score DESC`
- **回写**：定时任务每 60s：把 `idea:cnt:*` / `idea:view:*` 写回 DB 冗余计数与 `hot_score`（Lua 或 pipeline 批量，先读后写无锁场景用 WATCH 可简化为直接 SET）

### 4.3 定时任务

FastAPI 内 `asyncio` 后台任务（lifespan 启动）：
- **每 60s**：计数回写 DB（4.2）
- **每 10min**：重建 `idea:hot` ZSET（从 DB `hot_score` 全量 ZADD，防漂移）

### 4.4 读路径（计数显示）

列表/详情返回计数：**Redis 有则读 Redis，无则读 DB 并回填 Redis**。`liked_by_me` / `collected_by_me` 查 DB 唯一键（量小，不做 SET 缓存）。

### 4.5 降级策略

- 连接 Redis 失败 → logger.warning，全部读写**回退 DB**（计数直读 DB、排序用 `hot_score`、频控跳过）——功能可用、热度更新变慢，**不阻断主流程**
- 统一经 `services/idea_cache.py` 封装，业务层不直接摸 redis 客户端

## 5. API 契约（FastAPI）

> Base：`/api`，JWT 必带（复用 `get_current_user_id`），响应统一 `Result{code,msg,data}`（code!=200 即失败，http 拦截器会 resolve，调用方必须检查 `res.code`——沿用既有约定）。
> 新路由文件：`routers/idea.py`（prefix `/idea`），服务：`services/idea_service.py`、`idea_cache.py`。

### 5.1 草稿

| 方法 | 路径 | 请求 | 响应 data |
|------|------|------|-----------|
| GET | `/idea/drafts?q=&page=&pageSize=` | | `{list:[{id,title,summary,tags,sourceSessionId,updatedAt}], total}` |
| POST | `/idea/drafts` | `{title, content, tags[], sourceSessionId?}` | `{id}` |
| PUT | `/idea/drafts/{id}` | `{title?, content?, tags?, sourceSessionId?}` | null |
| DELETE | `/idea/drafts/{id}` | | null（连删文件） |
| GET | `/idea/drafts/{id}` | | `{title,content,tags,sourceSessionId}`（编辑器回填） |

### 5.2 发布

```
POST /idea/drafts/{id}/publish
body: { "withSnapshot": bool, "previewed": true }   // previewed 必须为 true（强制预览确认）
resp: { code:200, data:{ postId } }
```
- 服务端读草稿正文文件 → 写 `{postId}.json` + `summary` → `withSnapshot=true` 且有 `source_session_id` 时复制链为 `snapshot.json`（链遍历按 next 纯文件名约定）
- **同时删除草稿与草稿文件**（发布即转移，避免双份维护——文档 2.1 的"发布后草稿可改再发"修订为：**发布后草稿删除**，要再改去"我的帖子"改帖子。以此条为准）
- `previewed != true` → `code!=200 "请先预览快照"`

### 5.3 帖子

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/idea/posts?sort=hot\|new\|like&q=&tags=a,b&page=` | 广场列表；返回 `{list:[{id,title,summary,authorName,tags,view/like/comment/collectCount,hasSnapshot,createdAt,likedByMe?}],total}`（likedByMe 仅登录） |
| GET | `/idea/posts/{id}` | 详情（正文 content、tags、快照元信息）；**浏览+1**（Redis 去重）；他人已下架 → `code!=200` |
| GET | `/idea/posts/{id}/snapshot` | 快照全文 `{sourceSessionId, messages[]}`（仅发布者+广场公开状态可读；未附快照 → 404 语义） |
| PUT | `/idea/posts/{id}` | 作者编辑 `{title?, content?, tags?}`（**不可改快照**） |
| DELETE | `/idea/posts/{id}` | 作者下架（status=removed，**软删**；评论/快照文件保留） |
| GET | `/idea/mine/posts?page=` | 我的帖子（含已下架，带 status） |

### 5.4 互动与评论

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/idea/posts/{id}/like` | toggle → `{liked: bool, likeCount}` |
| POST | `/idea/posts/{id}/collect` | toggle → `{collected: bool, collectCount}` |
| GET | `/idea/mine/collects?page=` | 我的收藏（返回帖子摘要列表） |
| GET | `/idea/mine/likes?page=` | 我的点赞记录 |
| GET | `/idea/posts/{id}/comments?page=` | 评论平铺分页 `{list:[{id,authorName,content,createdAt,mine}],total}` |
| POST | `/idea/posts/{id}/comments` | `{content}`（≤500 字，频控 15s） |
| DELETE | `/idea/comments/{id}` | 作者删自己评论（计数-1） |
| GET | `/idea/tags?top=30` | 按帖子数排序的标签聚合（横向筛选条） |

### 5.5 错误约定

- 未登录 / token 失效：401（依赖层抛出）
- 越权（改别人的帖子）：`code!=200 "无权限"`
- 不存在/已下架：`code!=200 "帖子不存在或已下架"`
- 频控：`code!=200 "操作过于频繁，请稍后再试"`
- **测试断言一律 `code==200` / `code!=200`，不断言具体 code 数值**（与既有测试惯例一致）
